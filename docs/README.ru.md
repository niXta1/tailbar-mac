# Tailbar для macOS

Неофициальное приложение в менюбаре для **отдельного Homebrew `tailscaled`**.
Показывает устройства и состояние tailnet, позволяет подключаться, выбирать
exit node и проверять наличие локального прокси INCY/Happ. Кроме того,
Tailbar сохраняет работоспособность сети после сна Mac, смены сети и
перезапуска VPN-клиентов. Поддерживаются Apple Silicon и macOS 15+.

Приложение не содержит движок Tailscale, VLESS/Trojan-клиент или данные
подписки. Оно использует CLI и сокет `/var/run/tailscaled.socket`.
Официальное приложение Tailscale — отдельный клиент; Tailbar им не
управляет.

Интерфейс на английском, есть русский перевод. Tailbar показывается
на русском, если русский стоит первым в списке языков macOS или выбран для
Tailbar в «Системные настройки → Основные → Язык и регион → Программы».

## Быстрая установка

1. Установите `brew install tailscale` и запустите службу:
   `sudo brew services start tailscale`.
2. Проверьте связь с демоном:
   `/opt/homebrew/opt/tailscale/bin/tailscale --socket=/var/run/tailscaled.socket status`.
3. Скачайте ZIP из [Releases](https://github.com/s1ttt/tailbar-macos/releases),
   проверьте SHA-256 и перенесите `Tailbar.app` в «Программы».
4. Откройте приложение. Первый запуск создаёт значок в менюбаре; повторное
   открытие или пункт **Открыть Tailbar** (Open Tailbar) показывает окно. Включите
   Tailscale, пройдите вход и при необходимости выберите exit node.

Обновляетесь с **Tailnet Bridge 0.5** (`TailscaleMenuBar.app`)? Удалите
старое приложение и заново включите **Запускать при входе в систему**
(Launch at login) — подробности в
разделе [Upgrading from 0.5](INSTALL.md#upgrading-from-05-tailnet-bridge--tailscalemenubarapp).

Бинарный пакет подписан ad-hoc, но не нотариализован Apple. Если macOS
заблокирует запуск, используйте [официальную процедуру Open Anyway](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac).
Подробности сборки из исходников и удаления — в [INSTALL.md](INSTALL.md).

## Значок в менюбаре

Значок — девять точек:

- **Подключено:** горящие точки складываются в мостик.
- **Трафик идёт через exit node:** добавляется верхняя точка (кольцо, если
  exit node не отвечает).
- **Предупреждение:** кольцо в центре.
- **Подключение:** мостик собирается по точке.
- **Отключено:** все точки тусклые.

Цвет верхней левой точки:

- обычная: INCY/Happ и локальный прокси не обнаружены;
- янтарная: клиент INCY/Happ запущен, но нужный порт не слушает;
- зелёная: локальный TCP-порт прокси доступен.

Открытый порт не доказывает, что прокси работает или что публичный трафик
идёт через exit node. Зелёная точка на иконке в **Dock** постоянная и не
показывает состояние сети.

Без прокси приложение позволяет подключить Tailscale напрямую. В сети с
белым списком может понадобиться существующий клиент VLESS/Trojan. В проекте
есть **необязательные** wrapper и помощник маршрутов INCY TUN; они требуют
отдельной установки с правами администратора и описаны в
[NETWORKING.md](NETWORKING.md). Просто установка `.app` их не включает.

## Сон и пробуждение Mac

Если в INCY/Happ включено «не отключать VPN при сне», работающий Tailscale
после закрытия крышки ломал сеть: приходилось закрывать все приложения,
выключать Wi-Fi и подключаться заново. Теперь приложение делает это само
(**Настройки → Сон и пробуждение**, Settings → Sleep and wake; включено по
умолчанию):

- перед сном выполняет `tailscale down` и ждёт, пока исчезнут маршруты
  `0/1` и `128.0/1`; INCY/Happ не трогает;
- после пробуждения ждёт Wi-Fi/Ethernet без ограничения по времени (к точке
  доступа телефона можно подключиться вручную, меню подскажет), затем до 45 с
  ждёт TUN/прокси INCY/Happ и выполняет `tailscale up` с тем же exit node;
  ручное подключение в это время отменяет автоматическое;
- проверяет состояние `Running` и `tailscale ping` до exit node, при неудаче
  повторяет цикл и показывает уведомление.

Тот же цикл можно запустить вручную: пункт **Переподключить Tailscale**
(Reconnect Tailscale) в меню или
кнопка в настройках. Если приложение не запущено во время сна, оно ничего не
останавливает.

## Защита от «Wi-Fi есть, интернета нет»

Переход с точки доступа телефона на домашний Wi-Fi, закрытие INCY/Happ или
выключение exit node могут оставить Mac без интернета при подключённом Wi-Fi.
Причины бывают такие: пропал маршрут по умолчанию, маршрут ведёт в «мёртвый»
туннель, DNS всё ещё указывает на INCY или Tailscale. Раньше помогало только
закрыть всё и переключить Wi-Fi. Теперь это делает приложение (переключатель
**Автоматически обнаруживать и чинить неработающую сеть** в настройках,
Detect and repair a broken network automatically; включён по умолчанию).

**Как оно проверяет:**
- Каждые 20 с и через 5 с после запуска или закрытия INCY/Happ проверяет
  маршруты и DNS.
- Раз в минуту проверяет доступность `captive.apple.com`. Это тот же адрес,
  который проверяет сама macOS.
- При выбранном exit node пингует его.
- Чинит, только если проблема держится не меньше 10 с.

**Как оно чинит:**
- Если завис только exit node, переподключает Tailscale.
- В остальных случаях останавливает Tailscale, выключает и включает Wi-Fi,
  ждёт сеть и INCY/Happ, затем возвращает Tailscale с тем же exit node.
- Автоматических попыток не больше двух. Если не помогло, приходит
  уведомление «Сеть всё ещё не работает» (Network still broken).

**Починить сеть** (Repair Network) в меню, настройках и окне **Диагностика**
(Diagnostics) запускает ремонт
вручную. Помощник маршрутов (если установлен) сам возвращает пропавший
маршрут по умолчанию примерно за 3 с.

## Что приложение делает с системой

Tailbar читает состояние и выполняет команды Tailscale: те, что выбрали вы,
а также остановку Tailscale перед сном и возврат после пробуждения. При
включённом ремонте сети оно может перезапустить Wi-Fi. Маршруты само не
меняет, прав администратора не требует. Закрытие окна сохраняет менюбар и
соединение. Пункт **Завершить** (Quit) закрывает только интерфейс: фоновый `tailscaled` и
текущее состояние VPN остаются как есть, но защита при сне и ремонт сети не
работают, пока Tailbar не запущен.

## Лицензия и товарные знаки

Исходный код распространяется по [BSD-3-Clause](../LICENSE). Код и графика
Tailbar собственные: значок в менюбаре и иконка в Dock рисуются в коде,
чужих изображений приложение не содержит и не читает. Tailscale — товарный
знак Tailscale Inc.; INCY и Happ принадлежат своим владельцам. Названия
упоминаются только для указания совместимости. Проект не связан с
разработчиками Tailscale, INCY или Happ и не одобрен ими. Личных данных, подписок,
ключей и реальных снимков сети в репозитории нет.
